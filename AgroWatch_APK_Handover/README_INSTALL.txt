AGROWATCH MOBILE APPLICATION - INSTALLATION & USER GUIDE (v1.0)
================================================================================

1. INSTALLATION STEPS
---------------------
Prerequisites:
- Android 7.0 (API level 24) or higher.
- Minimum 100 MB free storage space.
- Active Internet Connection (for live API sync & AI model inference).

Step-by-step Installation:
1. Transfer 'Agrowatch_v1.0.apk' to your Android smartphone (via USB, WhatsApp, or Google Drive).
2. Open the File Manager app on your Android device and locate 'Agrowatch_v1.0.apk'.
3. Tap on the APK file to initiate installation.
4. If prompted with "Install unknown apps" or "Allow from this source", navigate to:
   Settings -> Security & Privacy -> Install Unknown Apps -> Toggle ON for your File Manager.
5. Tap "Install" and wait for the process to complete.
6. Open the AgroWatch application from your home screen or app drawer.
7. Grant required runtime permissions (Camera & Storage) when prompted to enable crop scanning functionality.

----------------------------
